# ぱらえ - パラパラマンガが作れるお絵かきメモ

スマホ利用をベースにした、パラパラマンガ作成ツールのMVPです。
ビルドなし、単一の `index.html` だけで GitHub Pages で公開できます。

## MVPの機能
- 指／マウスで描画（ペン・消しゴム・塗りつぶし、色6色、太さ変更）
- コマの追加・コピー・削除、サムネイルから移動。キャンバス直下のコマ操作バーに前後・追加・コピーを集約
- コマの並べ替え：今のコマを左右のコマと入れ替えるボタン（⬅ 左へ／右へ ➡）＋サムネイル長押し→左右ドラッグで任意の位置へ移動
- 誤リロード対策：自動保存（localStorage）＋離脱直前の保存、作品があるときはリロード／タブを閉じる前にブラウザ確認を出す、引っ張って更新は overscroll-behavior で抑止
- 前のコマを透かす（オニオンスキン）
- 再生（1〜24 FPS、ループ）
- 戻す（アンドゥ）／進める（リドゥ）、白紙化
- キャンバスのピンチ拡大（1〜4倍）・2本指での表示移動、100%リセット（コマ移動・再生時は自動で100%に戻る）
- ボタン連打時のダブルタップ拡大防止（touch-action + JSフォールバック、連打自体は効く）
- ブラウザ内への自動保存（localStorage、今の作品1つ分）
- 作品の複数保存：「名前をつけて保存」で名前付きスロットに複数作品を保存し、一覧から開いて編集再開・削除ができる。加えて作品ファイル（JSON）の書き出し／読み込みで、編集可能な形のままバックアップや端末間移動ができる
- 保存まわりは3セクション構成（2026-11-07 本人指定）: 「ぱらえファイル（編集できる形で保存）」＝新規・保存・名前をつけて保存・一覧から開く/削除・ファイルに保存/ファイルを開く／「変換して保存」＝画像で保存（全コマを横に並べた1枚PNG）・動画で保存（WebM）・今のコマを保存（PNG）／「共有」＝動画を共有・今のコマを画像で共有
- 共有：Web Share APIで動画（WebM）／現在のコマ（PNG）をスマホの共有シートからX・LINE等へ渡せる。ファイル共有に未対応の環境ではダウンロードにフォールバックし、共有シートをキャンセルした場合は何もしない

## GitHub Pagesでの公開手順
1. GitHubで新規リポジトリを作成（例: `parae`、Public）
2. このフォルダの `index.html` と `.nojekyll` をリポジトリのルートに置いて push
3. リポジトリ Settings → Pages → Source を `Deploy from a branch` / `main` / `/ (root)` に設定
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
