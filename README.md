# ぱらえ - パラパラマンガが作れるお絵かきメモ

スマホ利用をベースにした、パラパラマンガ作成ツールのMVPです。
ビルドなし、単一の `index.html` だけで GitHub Pages で公開できます。

## MVPの機能
- 指／マウスで描画（ペン・消しゴム・塗りつぶし、色6色、太さ変更）
- 全体移動ツール：今のコマの絵全体をドラッグでずらせる（コピーしたコマの位置調整用）。PCでは全体移動モード中に矢印キー（Shiftで10px）でもずらせる。履歴対象なので戻す／進めるで取り消せる
- コマの追加・コピー・削除、サムネイルから移動。キャンバス直下のコマ操作バーに前後・追加・コピーを集約
- コマの並べ替え：今のコマを左右のコマと入れ替えるボタン（⬅ 左へ／右へ ➡）＋サムネイル長押し→左右ドラッグで任意の位置へ移動
- コマ削除：削除ボタンに対象番号を表示し、確認ダイアログでも「コマ N（全Mコマ中）」と明示。各サムネイル右上の × からそのコマを直接削除することもできる。「複数削除」モードではサムネイルをタップで複数選択（✓マーク）して一括削除でき、履歴1件として記録されるため「戻す」で一括復元できる
- 誤リロード対策：自動保存（localStorage）＋離脱直前の保存、作品があるときはリロード／タブを閉じる前にブラウザ確認を出す、引っ張って更新は overscroll-behavior で抑止
- 前のコマを透かす（オニオンスキン）
- 再生（1〜24 FPS、一周したら自動で止まり、編集していたコマに戻る。書き出し動画も1周のみ）
- 戻す（アンドゥ）／進める（リドゥ）: 履歴は作品全体が対象で、描画・白紙化に加えてコマの追加・コピー・削除・並べ替え・FPS変更も戻せる（最大30回分、コマ移動しても履歴は消えない）
- タイムラインの自動スクロールはコンテナ内の横スクロールのみで、ページ全体は動かさない（PCで描画後に画面が下へずれる問題への対処）
- キャンバスのピンチ拡大（1〜4倍）・2本指での表示移動、100%リセット（コマ移動・再生時は自動で100%に戻る）
- ボタン連打時のダブルタップ拡大防止（touch-action + JSフォールバック、連打自体は効く）
- ブラウザ内への自動保存（localStorage、今の作品1つ分）
- 作品の複数保存：「名前をつけて保存」で名前付きスロットに複数作品を保存できる。保存した作品はサムネイル付きの一覧で表示され、各作品に「開く／上書き（今の作品でそのスロットを更新）／名前変更／削除」がある。加えて作品ファイル（JSON）の書き出し／読み込みで、編集可能な形のままバックアップや端末間移動ができる
- 保存まわりのセクション構成（2026-11-07 本人指定）: 「ぱらえファイル：ブラウザ上で保存」＝新規・保存・名前をつけて保存・一覧から開く/削除（注意書き付き：端末とブラウザ内にのみ保存、ファイルにならない、容量上限あり。自動保存の成否表示あり）／「ぱらえファイル：ファイルとして保存」＝ファイルに保存（parae-日時.json）/ファイルを開く（注意書き付き）／「変換して保存」＝画像で保存（全コマZIP：1コマずつ連番PNGをZIP化。横長に繋げた1枚画像は廃止）・動画で保存（MP4で録れる環境ではMP4優先、ダメならWebM。作品が変わらない間はキャッシュ）・今のコマを保存（PNG）／「共有」＝動画を共有・今のコマを画像で共有
- ツールバーの並び（2026-11-07 本人指定）: 1段目＝ペン・消しゴム・塗り、2段目＝戻す・進める・白紙（戻すと進めるを隣に置く）
- 共有：Web Share APIで動画（WebM）／現在のコマ（PNG）をスマホの共有シートからX・LINE等へ渡せる。ファイル共有に未対応の環境ではダウンロードにフォールバックし、共有シートをキャンセルした場合は何もしない
- アクセス計測：Googleタグ（`GTM-KJH9FLC5`、送信先GA4 `G-FNRPR55FRB`）で閲覧数と主要ボタン・ハブリンクの利用回数を集計する。作品の内容やファイル名は送信しない
- ページ下部に、もずくの活動まとめ（https://mozk-umino.github.io/）へのリンクを置く

## GitHub Pagesでの公開手順
1. GitHubで新規リポジトリを作成（例: `parae`、Public）
2. このフォルダの `index.html` と `.nojekyll` をリポジトリのルートに置いて push
3. リポジトリ Settings → Pages → Source を `Deploy from a branch` / `main` / `/ (root)` に設定
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
